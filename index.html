🔗 Kết Nối Google Sheet Cố Định

Bằng cách tạo 1 Webhook miễn phí trên Google Sheet của bạn, Tool sẽ tự động gửi toàn bộ từ vựng đã bóc tách thẳng vào trang Google Sheet cố định của bạn 24/7!

📋 Hướng dẫn 3 bước thiết lập (Chỉ làm 1 lần):

  1. Mở file Google Sheet của bạn ➔ Chọn menu Extensions (Tiện ích mở rộng) ➔ Apps Script.
  2. Dán đoạn mã dưới đây vào rồi bấm Deploy (Triển khai) ➔ New deployment ➔ Select type: Web app ➔ Who has access: Anyone.
  3. Copy link Web app URL dán vào ô bên dưới rồi bấm Lưu Kết Nối!
